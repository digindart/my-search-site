# PAY INSIGHT

기존 Render / MariaDB 서비스를 유지하는 Node.js 20+ 애플리케이션입니다.

## 실행

`.env.example`을 참고해 로컬 `.env` 또는 Render 환경변수를 설정합니다. 키와 비밀번호는 커밋하지 않습니다. `npm ci`, `npm start`로 실행합니다. 서버는 `PORT`를 사용합니다. DB에는 기존 `salary_data` 테이블이 필요합니다. 웹서버는 기존 스키마를 변경하지 않습니다.

## 추가 페이지

`/rankings`에서 증권사·보험사·은행과 삼성·현대·현대차·SK·한화·롯데의 별도 서버 렌더링 페이지로 연결됩니다. 선정 회사는 `data/categories.json`에 명시합니다. 이는 전체 업권 또는 연도별 공식 기업집단 전체를 보장하는 목록이 아닙니다. 회사 편입·분리와 상호 변경은 원문 확인 후 목록을 갱신합니다. 현대그룹과 현대차그룹은 별도로 분류합니다.

공시된 개인 보수총액 순위이며 직원 평균 연봉이 아닙니다. 동액은 공동 순위, 같은 행은 중복 제거, 회사 간 개인 보수는 비합산입니다. 음수 및 1,000억 원 초과 값은 검토 대기로 분리하며 실제 DB 금액을 추측해서 고치지 않습니다. 검색 CSV는 원본 금액과 검토 상태를 포함합니다.

인물의 ‘더 알아보기’는 성명·회사·직위·사업연도를 전달하는 네이버 **뉴스 검색**을 새 창으로 엽니다. 기사를 수집하거나 인물과 연결된 사실이라고 단정하지 않습니다.

Google 광고 스크립트는 제거했습니다. 검색 전에도 읽을 수 있는 업권·그룹 해설과 출처·해석 안내를 제공하지만 AdSense 승인 자체를 보장하지 않습니다. 광고 재도입은 콘텐츠 및 정책 재검토 후 진행해야 합니다.

## 2024·2025 OpenDART 수집

기준은 **사업연도** 2024, 2025이며 사업보고서 코드 `11011`입니다. 제출연도 2024/2025의 보고서 목록을 의미하지 않습니다.

공식 API: https://opendart.fss.or.kr/guide/detail.do?apiGrpCd=DS002&apiId=2019014

1. `DART_API_KEY`를 `.env`에 설정합니다. 키는 출력하지 않습니다.
2. 대표 회사 원문으로 응답 금액 단위를 확인한 뒤 소규모 파일을 먼저 수집합니다. 다음 예시는 단위를 **원으로 확인한 경우**입니다.

```sh
python3 scripts/fetch-dart.py --env .env --unit 원 --corp-codes 00126380 --out var/pilot
```

3. `var/pilot/raw`의 원문 응답, `staged.json`의 정제 결과와 `review.json`의 검토 항목을 대조합니다. 원문의 접수번호로 DART 공시를 확인합니다. 유니코드·공백·줄바꿈·명확한 주석 번호만 자동 정리하고, 前·퇴임·겸직은 보존합니다. 금액은 십진수로 처리해 정수 원으로 변환합니다. 불명확한 값은 0원으로 바꾸지 않습니다.
4. 전체 수집은 상장사 전체와 기존 이름으로 대응되는 비상장사를 대상으로 합니다. 기존 SQL 백업을 명시하면 기존 상호를 유지합니다. 상호가 달라 매칭되지 않는 회사는 별도 확인이 필요합니다.

```sh
python3 scripts/fetch-dart.py --env .env --unit 원 --legacy-sql ../salary_data.sql --out var/dart
```

특정 회사·연도에 원문으로 확인한 다른 단위가 있으면 `--units`에 `{"00126380/2025":"백만원"}` 형태 JSON 파일을 지정합니다. 금액 크기로 단위를 추정하지 않습니다. 단위 및 입력 조건을 바꿔 실행하면 캐시된 원문을 다시 정규화합니다. 원문 캐시를 최신 정정공시로 새로 받으려면 새로운 `--out` 경로를 사용합니다. 검토 파일을 임의로 편집해 검증을 우회하지 마세요.

`013`은 자료 없음으로 기록하며 보수 0원을 만들지 않습니다. 인증·한도 오류는 중단하고 완료되지 않은 패키지는 DB에 반영할 수 없습니다. 수집 범위·성공/누락·실패 건수와 원문을 로컬 `var/`에 보관하며 Git에서 제외합니다. 수집 결과에 법인별 보수 공개 정보가 없는 회사도 있을 수 있습니다.

5. 드라이런으로 입력을 검증합니다. 운영 DB를 백업한 다음 `--apply`를 추가합니다.

```sh
node scripts/apply-dart.js var/dart/staged.json
node scripts/apply-dart.js var/dart/staged.json --apply
```

검토 대기 항목이 있으면 기본적으로 적용을 중단합니다. 원문 확인이 끝나지 않은 항목을 제외하고 검증된 행만 적용하려면 `--skip-pending`을 명시합니다. 이 경우 전체 수집·반영 완료로 간주하면 안 됩니다.

기존 2021~2023 자료는 삭제하지 않습니다. 신규 행은 기존 컬럼 형식으로 저장하고, 별도 `salary_dart_sources` 테이블에 원문·직위 변경 내역·원 단위 변환에 사용한 단위·접수번호·패키지 체크섬을 보관합니다. 동일 자료를 다시 적용해도 중복을 만들지 않습니다. 같은 회사·연도·성명에 다른 값이 있으면 충돌로 전체 트랜잭션을 롤백합니다. 정정공시를 기존 행에 반영하는 작업은 원문 대조 후 별도 수행해야 합니다. 적재 중에는 DB advisory lock을 사용합니다.

## 기존 Excel 가져오기

`import.js`는 기존 전체 삭제 방식을 유지하되 `--replace-all` 없이는 실행을 차단합니다. 신규 연도 추가에는 사용하지 마세요. 기존 파일의 단위 이상치는 원본 공시와 대조해야 하며 자동으로 일괄 배수를 적용하지 않습니다.

## 검증 및 배포

```sh
npm test
PYTHONDONTWRITEBYTECODE=1 python3 -m unittest discover -s test -p 'test_*.py'
```

Node 테스트의 HTTP 서버는 로컬 포트 권한이 필요합니다. 통합 테스트는 DB를 모의 처리하므로 실제 MariaDB 적재 및 운영 DB 부하 검증을 대신하지 않습니다.

Render 시작 명령은 `npm start` 또는 `node server.js`입니다. 운영 환경변수와 기존 DB 연결 설정을 유지합니다. 배포 후 `/api/years`, 회사 검색, `/rankings`, `/methodology`, CSV 및 외부 뉴스 링크를 확인합니다. 운영 DB 접근 정보와 OpenDART 키 없이는 실제 수집·반영을 완료할 수 없습니다.

기존 저장소의 DB 비밀번호 리터럴은 제거했습니다. 과거 Git 기록은 남아 있으므로 실제 사용 계정의 비밀번호는 교체해야 합니다. 기존에 추적 중인 `node_modules` 정리는 이번 변경에 포함하지 않았습니다.

### 원문 확인 후 개별 정정

명확한 오타 또는 불필요한 문구를 선별 수정할 때는 `--corrections` JSON을 사용합니다. 키는 `법인코드/사업연도/접수번호/원문성명`이며, 변경할 `employee_name`, `position_name`, `compensation`(정수 원 문자열), 필수 `reason`, 해당 접수번호와 일치하는 `evidence_url`을 제공합니다. 수집을 재실행하면 원문 캐시를 보존하면서 수정 이유와 전후 값을 적재 이력에 남깁니다. 원문 확인 없는 직위 추측이나 금액 배수 변경은 하지 않습니다. 사용되지 않은 정정 키가 있으면 전체 패키지 완료 처리를 차단합니다.


## 2026-11-14 수집 및 DB 반영 결과

대상 DB에 기존 백업 16,164건을 복원하고 2024년 2,584건, 2025년 2,671건을 추가했습니다. 총 21,419건이며 신규 자료의 완전 중복은 0건입니다. 원본 백업과 비교해 기존 2021~2023 자료가 그대로 보존됨을 확인했습니다. 동일 수집본 재실행 결과 신규 삽입은 0건이었습니다. 운영 Render의 DB 환경변수와 서비스 배포 전환은 별도 작업입니다.

전체 10,374개 회사·연도 조합을 조회했습니다. 대시·공란 또는 이름/직위 없는 0원 placeholder는 미공개 행으로 기록하고 개인 데이터에 넣지 않았습니다. API의 `013` 역시 0원 보수로 만들지 않습니다. 익명 공시명(김OO, ○○○, *)은 그대로 보존하고 인물 기사 링크를 제공하지 않습니다. 서로 다른 익명 공시 행을 동일 인물이라고 단정하지 않습니다.

`data/dart-corrections-2024-2025.json`에 원문 대조한 46개 항목의 정제 근거와 공시 링크, 원본 XML 체크섬을 보관했습니다. 전체 수집본을 다시 생성하려면 기존 명령에 `--corrections data/dart-corrections-2024-2025.json`을 추가합니다. 공개 통계는 `data/import-summary-2024-2025.json`에서 확인할 수 있습니다. 원문 API 응답·공시 XML·실제 DB 백업은 Git에서 제외한 `var/`에만 보관합니다.

금액 크기만으로 배수를 적용하지 않았습니다. 제일일렉트릭 2024년은 동일 공시의 개인별 보수표와 산정기준 단위를 대조해 천원 기준으로 정정했습니다. 네오이뮨텍은 표 머리말과 달리 USD임을 명시한 주석을 확인하고, 공시에 기재된 당기 평균환율(2024년 1,363.98원/USD, 2025년 1,422.22원/USD)로 환산해 원 미만 반올림했습니다. 각 정정 항목에 환율·원금액·이유를 기록했습니다. 외국계 상장사는 금액이 작더라도 원문 통화를 검토했습니다.

직위가 보수표에 없는 경우 동일 공시의 임원 변동표나 보수 산정기준에서 확인 가능한 항목만 보완했습니다. 근거가 없는 직위는 `미기재`로 표시했습니다. 각 사유는 정정 파일과 DB 출처 이력에 남습니다. 신규 익명 이름은 실명으로 추정 복원하지 않습니다.

DB 운영 보조 도구는 `scripts/check-db.js`, `scripts/locate-db.js`, `scripts/backup-db.js`, `scripts/verify-db.js`, `scripts/smoke-live-db.js`입니다. `restore-legacy.js`는 완전히 빈 대상 DB에서만 실행되며 기존 테이블이 있으면 중단합니다. `verify-db.js`는 이번 백업 및 5,255건을 기준으로 만든 검증 도구입니다. 이후 데이터가 늘어나면 기대 건수를 갱신해야 합니다.
